# 日程与待办

后台「日程与待办」管理未完成、已完成和只读日历。默认没有任务或订阅；不会替用户添加日历地址。

## 待办

标题、备注、截止时间和 0–3 优先级可以修改；完成后可重新打开，永久删除需要确认。界面时间按当前设备时区填写，接口使用 Unix 秒，0 表示不设截止时间。

资产列表、资产到期条目、告警事件和情报条目可「转成待办」。引用为 `asset:id`、`event:id` 或 `intel:id`，保留标题和备注快照，不复制保险箱字段。访问密钥还需要来源模块的读取权限。同来源已有未完成待办时返回原项，完成后可以再次创建。

`todo.remind` 每五分钟检查，在截止前 24 小时、1 小时及到期时各提醒一次；修改截止时间或重新打开后重新计算。超过批量上限的待提醒项下轮继续，已经提醒的旧任务不会挡住后面的任务。提醒进入既有通知队列，通知出口未配置时不会对外发送。单次列表最多显示 500 项。

## 只读日历

填写 Apple、Google 等服务的私有 HTTP/HTTPS ics 地址和 IANA 时区；`webcal://` 地址需换成对应的 HTTPS 地址。地址通过保险箱加密保存，列表和编辑表单只返回是否存在；不提供读回地址的接口。清除地址会暂停订阅，删除订阅也删除地址和本地日程。

`ical` 实现 `connector.Connector` 和条件抓取。订阅地址只作为连接器的 secret 传入，配置中仅有时区。它独立于情报来源，不能把私有日历通过情报接口保存。请求复用公网 DNS 校验、固定连接、重定向限制，不发送 Referer；上游错误和私有地址不进入错误响应。

使用 `go-ical` 解析、`rrule-go` 展开每日、每周、每月、每年重复日程，支持 RDATE、EXDATE、单次改期和取消，按时区处理夏令时。全天事件按本地日期递增。秒、分、小时级重复、过密规则、特殊自定义时区和 `RANGE=THISANDFUTURE` 等不能安全处理的内容会报错，保留上次成功快照；不会静默丢弃后覆盖日程。

每次最多读取 1 MB、5000 个主/例外条目，展开最近 30 天到未来 180 天，最多保存 2000 个发生项，并有计算次数上限。使用 ETag / Last-Modified；每天至少完整读取一次，重新计算滚动窗口。`calendar.sync` 每分钟检查到期来源，最多四个并发，一个失败不阻止其他来源。同步失败保留旧数据，成功快照替换本地日程，远端取消或删除会同步消失。暂停订阅后不展示其日程。

私有地址加密不代表日程正文加密：本地日程和待办保存在主数据库，备份应按私人数据保护。

## 简报与能力

每日简报「今天」合并今天的日程、今天到期和已经逾期的未完成待办，使用简报选择的时区。

- `todo.list/create/update/complete/delete`、`todo.from_ref`。
- `calendar.today`、`calendar.range`（最多 366 天）。
- `calendar.sources/add_source/update_source/delete_source/sync`。

全部能力通过注册表进入 API、MCP、OpenAPI 和 Skill。删除是 Danger；访问密钥仍只能使用能力接口，不能进入后台接口。日历没有写入、发邀请或修改远端事件的能力。
