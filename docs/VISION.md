# TZA CC 目标

## 一句话
**TZA CC 是一个部署在自己服务器上的个人中枢：完整掌握我的资产和状况，持续收集和我相关的信息，到点主动提醒我，经我同意后替我办事。**

它从服务器管理起步（主机监控、代理、证书、备份），但服务器只是其中一类资产。以后每一步都按这份文档排优先级。

## 功能

### 1. 资产
记录我拥有或在付费的东西：服务器、域名、证书、各类订阅服务（AI、流媒体、云服务等）、设备、证件、保险。
- 每样都记录费用、币种、续费周期、到期时间。
- 到期前提醒，到期情况进总览和简报。
- 机器的监控、代理、证书等现有功能，作为「服务器」这一类资产的专属能力保留。

### 2. 财务
资产管「有什么」，财务管「钱怎么流动」。
- 收入和支出记账、订阅总支出、预算、净资产随时间的变化、多币种折算。
- 只记账、只查看，不接任何交易或转账。

### 3. 情报
持续收集和我相关的外部信息：RSS、网页变化、GitHub Release、补货和降价、汇率、行业新闻。
- 命中关键词或规则就立即推送；其余的放进每日简报。
- 每条情报都保留来源链接。

### 4. 记忆和知识库
- 笔记、书签、文章摘录、文件都能放进来，以后能检索。
- 助理记住我的偏好、习惯和做过的决定，越用越懂我。

### 5. 日程和待办
- 日历、提醒、待办，可以接 Apple 或 Google 日历。
- 资产到期、告警、情报都可以一键转成待办，让「发现问题」和「把事办掉」接上。

### 6. 自动化（执行层）
- 规则写成「触发 → 条件 → 动作」，比如「某机器离线超过 10 分钟 → 重启服务 → 失败再通知我」。
- 定时任务、Webhook、助理提出的动作，都在这里执行。
- 所有动作分级：只读的直接做；有风险的（重启、删除、改配置、和钱有关的）先列出来，等我确认。

### 7. 数字身份和安全
- 账号清单、2FA 恢复方式放在哪、密码泄露监测、登录异常。
- 域名和证书的风险也归到这里。
- 盘点我在网上有哪些身份，哪些地方有风险。

### 8. 助理（大脑）
- 接入大模型，能调用面板自己的能力（MCP 已有），回答「这个月一共花了多少」「哪些东西下个月到期」这类问题。
- 每天早上生成简报：资产到期、机器状态、关注的情报、今日待办。
- 能提出动作，但有风险的动作必须经我确认（见第 6 条）。

### 9. 可选（以后再定）
- 家里的设备、NAS、智能家居（接 Home Assistant）。
- 健康数据：睡眠、运动、体重，可以从 Apple 健康导入。
- 邮件摘要：汇总账单、续费通知、重要来信。比较敏感，放到最后。

## 入口
先做给 agent 用的入口：主要由外部 agent（Claude Code 等）来管理它。
1. **API**：每项功能都能通过 API 完成，带说明文档（OpenAPI）。用可以随时吊销的密钥访问，每把密钥单独设权限范围。
2. **MCP**：覆盖全部模块，不只限于节点和任务；有风险的操作明确标注出来。
3. **Skill**：给外部 agent 的使用说明包，讲清楚有哪些能力、该怎么用、哪些操作要先问我。可以从面板下载。
4. **网页端助理**：在面板里和它对话。大模型走 magpie 网关，能力和 MCP 是同一套。

以后再做：Telegram、iPhone 快捷指令、语音、每日简报推送。面板做成 PWA，可以装到手机桌面。

## 底座
- **通用数据模型**：不管什么东西，都统一成「实体 + 时间线 + 标签」。告警、操作、到期、情报、简报都写进同一条时间线。
- **隐私分级**：敏感字段加密保存（主口令解锁）；助理默认看不到最高级的数据。
- **权限**：我是唯一的主人；朋友只能用代理和转发；以后也可以给家人开有限的权限。
- **全程审计**：每次操作都能追溯。
- **备份**：加密异地备份（已有）。
- **应急交接**（可选）：我失联超过设定的天数后，把指定信息交给我指定的人。

## 明确不做
- 不做交易，也不碰转账。
- 不做多人协作平台。
- 不训练自己的模型，直接调用现成的大模型。

## 怎样算做成了
- 每天早上第一个打开的就是它。
- 问一句话，就能得到任何关于我自己的答案。
- 不再漏掉任何一次到期或续费。
- 重复的小事不用我再动手。
