# UI 信息架构重构

这轮把后台从服务器工具清单调整为个人中枢。页面继续使用原生 JavaScript 与既有主题令牌，沿用现有 API、鉴权和危险操作确认机制。

## 导航

主导航保留六个区域，每次只展开一个区域。切换页面时展开当前页面所属区域，并更新高亮与「区域 / 页面」面包屑。

| 区域 | 页面 |
| --- | --- |
| 工作台 | 今天、日程与待办、告警与事件、每日简报、助理、时间线 |
| 情报 | 信息流与订阅 |
| 资产与财务 | 资产清单、财务账本、账户安全 |
| 基础设施 | 节点管理、网络探测、远程管理；代理、转发、共享使用者；网站、证书、容器 |
| 自动化 | 规则与执行，页内分为规则、待确认、执行记录 |
| 系统设置 | 偏好与账号、通知渠道、访问密钥与接入、外观主题、插件、系统备份、审计日志 |

导航元数据在 `web/admin-navigation.js`，渲染函数映射与导航 HTML 在 `web/admin-pages.js`。新增页面必须同时登记元数据与渲染函数。

通知出口从告警规则页移到系统设置；规则页保留跳转入口。账户资产的保护状态归资产与财务，后台登录与两步验证仍归系统设置。系统备份指 Lodestar 主控数据的加密备份。

## 今天

首屏优先展示需要处理的异常、到期提醒、逾期待办和自动化待确认提示；随后是今天的日程与到期待办、未读情报和最新已发送简报摘要。资产、财务、节点与安全的摘要放在后面，其余模块状态默认折叠。

日程按浏览器本地时区查询，日期边界按日历日计算。来源请求分别容错，失败明确显示未知，不把读取失败当作正常或空数据。首页每分钟刷新；弹窗、手机导航或后台标签页打开时暂停刷新，离开首页时清理定时器，过期响应不能覆盖其他页面。

每日简报有独立工作台入口，可查看最新简报、进入历史记录，并展开发送设置。打开页面不会调用模型生成预览，也不会发送通知。

## 路由与交互

既有页面 ID 保持稳定。地址片段保存页面与主要子页，例如 `#finance/transactions`、`#todo/calendar`、`#automation/pending` 和 `#settings/assistant`。刷新、浏览器前进和后退能恢复这些位置；旧的其他后台入口仍由原有公开页路由管理。

手机常驻「今天 / 待办 / 助理 / 更多」快捷入口，其余导航使用覆盖式抽屉，正文不随菜单展开向下移动。抽屉内滚动，背景正文不可交互；支持遮罩关闭、Escape、Tab 焦点循环与关闭后焦点返回。桌面保留侧栏和常驻助理入口。

页内内容切换统一使用可横向滚动的二级导航。低频配置、执行记录和日常内容各自拥有明确入口。

## 验证

`scripts/navigation-test.mjs` 覆盖导航归属、渲染函数登记、路由恢复、今天的日期筛选、内容转义、来源失败和旧响应隔离，并接入完整流水线。`scripts/ui-smoke.mjs` 同步验证新的首页顺序与通知渠道入口；财务、待办、情报、自动化与安全的既有行为测试继续运行。

真实浏览器验收使用隔离的本机数据目录，不写入生产示例数据。用户于 2026-11-16 明确授权提交、推送和部署，本轮以 v3.10.0 发布，同时提交此前已实现并部署的 v3.3—v3.9 模块源码与记录。

最终验收：

- 完整 `bash scripts/pipeline.sh check` 通过：43 个 Go 包、vet、竞态、前端行为与一次性 Server 集成。日志为 `/tmp/lodestar-ui-refactor-accepted.log`；角色包自检因缺少 Pillow / numpy 跳过，与本轮页面修改无关。
- Chromium 桌面 1440×900、手机 375×812 验证，27 个页面均可打开且手机无横向溢出。财务和待办子页刷新、浏览器后退、手机快捷入口、抽屉焦点循环与 Escape 返回均已检查。
- 首页浅色、深色与手机快捷导航的 axe 检查均为零问题；浏览器没有 JavaScript 错误。告警与通知设置连续五轮并发切换均停留在最后选择的通知页面。
