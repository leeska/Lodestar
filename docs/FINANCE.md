# 财务账本

后台「财务」记录账户、流水、月度预算和余额快照。默认没有账户，也不会替用户导入交易或填余额。

## 金额和账户

API 的金额采用十进制字符串，最多 14 位整数、2 位小数，例如 `"12.50"`、`"-0.08"`。数据库用整数表示两位小数金额，不用二进制浮点数记账；汇总和折算检查整数范围，溢出会拒绝写入或返回错误。

账户类型为现金、银行、投资、负债或其他。余额有两种方式：

- `ledger`：期初余额加上全部流水，收入或流入为正数，支出或流出为负数。
- `manual`：以用户填写的当前余额为准，流水仍保留用于收支和预算。

负债按负数填写。流水币种必须和账户一致；有流水的账户不能更换币种，删除账户前必须明确处理其流水。修改、删除流水会改变推算余额；历史快照保留。修改流水的账户不会自动换汇。

汇总币种默认为 CNY，统计和快照时区默认为 UTC，均可在「汇总设置」修改。当前月份由服务端按该时区给出。记账表单的时间按当前设备时区填写。

## 收支、预算和固定费用

月度收支汇总本地账本的正数流入、负数流出与净流入，不把期初余额或手工余额当成当月流水。预算按分类、月份和币种保存，同分类正数退款抵扣净支出；修改预算的分类或月份会更新原项。

跨币种使用 `internal/model/fx.go` 的固定参考汇率，只供估算，不代表当前市场汇率。它与既有前端 `FX_CNY` 数值通过测试保持一致。金额在合并后再折算并舍入，正负半分均向远离零的方向处理；图表中的浮点数只用于画坐标。

「固定支出」只读汇总未归档资产和节点的周期费用，按价格 × 30 ÷ 周期天数估算，年度按 365 天计算。一次性费用不计入；明确免费的节点计为 0，未填写或无法折算的费用显示“未知”。不自动产生流水。访问密钥只有同时获得来源模块读取范围，才能看到相应资产或节点费用；缺少范围的来源被省略。

## CSV 导入

支持 UTF-8、逗号/分号/制表符，最多 1 MB、2000 数据行。先读取表头，明确映射日期和金额，分类、备注、原始引用和币种可选。金额可以选无千分位、小数点加千分逗号、或欧洲小数逗号格式；错误分组不会被直接去掉后当成别的金额。

日期按所选 Go 时间布局与财务时区解析；界面提供常见年月日、日月年、月日年和 RFC 3339 选项。可显式反转金额符号。币种不符或任一行出错时，整份文件不会部分写入。

预览校验全部行，显示前 100 行和重复数量；修改内容或映射后必须重新预览。导入使用数据库事务。默认按账户、规范化行内容及同值出现次数识别已经导入的行；账户改名不改变识别，编辑同账户的导入记录也保留原导入标识。完全相同的新交易不能仅靠内容区分，建议映射原始交易编号到 `ref`，或明确取消去重。

网页与能力 API 支持上述文件上限，CSV 专用 JSON 请求上限为 8 MB，普通后台请求保持原限制。MCP 保留既有 256 KiB 单消息上限，大文件需拆分或走能力 API。CSV 仅传给用户自己的主控，不连接外部银行或支付系统。

## 每日快照

`finance.snapshot` 每小时检查，以财务时区的日期为键，每日首次记录账户余额、币种和净资产。没有账户时不制造零资产快照；手动“更新今日快照”会替换当天记录。数据库保留账户余额明细，曲线接口返回最近 400 个当前汇总币种的日快照合计，切换汇总币种不会混用历史曲线。

账户、流水、CSV 备注和快照是私人财务数据，保存在主数据库，应保护数据目录和备份。没有交易、转账、付款执行能力。

## 接口和能力

后台接口前缀 `/api/v1/admin/finance`：

- `settings`、`accounts`、`transactions`、`budgets`、`summary`、`recurring`、`snapshots`、`snapshot`。
- 账户、流水支持添加、修改和删除；预算 POST 按分类/月份/币种设置，PUT 按 ID 修改。
- CSV 使用 `POST csv/columns`、`POST csv/preview`、`POST csv/import`。

同名能力从注册表进入 MCP、OpenAPI 和 Skill。账户、流水和预算的删除属于 Danger，需要逐次确认；普通记账和设置属于 Write。

## 验证

单元测试覆盖小额精确计算、负余额、手工余额、退款预算、预算改名、账户间更正、币种限制、溢出拒绝、CSV 失败回滚、重复导入与账户改名、数字格式、每日快照和手动替换、组合汇率舍入及来源范围。

前端行为测试覆盖金额仍是字符串、账户/流水/CSV 转义、预算按 ID 更新、导入预览失效。一次性 Server 集成覆盖账户、流水、预算、快照、CSV 的真实保存与删除；大于普通请求限制的 CSV 预览也通过能力接口验证。
